## Datasets

### PV Time Series

The PV time-series lessons use **Photovoltaic (PV) Generation Dataset with Orientation Diversity** by Mehmet Çunkaş, Mustafa Arslan, and Hasan Huseyin Cevik, published on Zenodo.

- **Source and citation:** https://doi.org/10.5281/zenodo.19245713
- **License:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)

### PV Images

The PV image lessons use **PV_EL_HDR_BW_Test_DB**, published on Mendeley Data.

The dataset contains paired electroluminescence (EL), black-and-white (BW), and high-dynamic-range (HDR) images covering 84 states of two physical photovoltaic cells.

- **Source and citation:** https://doi.org/10.17632/pxyzzkbs4b.1
- **License:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
